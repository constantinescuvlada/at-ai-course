Describe the request shape (Pydantic)

Programs exchange data as JSON — text like {"title": "About us"} with named fields. A Pydantic model declares exactly which fields (and which types) a client must send.

FastAPI checks every incoming request against this declaration automatically — wrong or missing fields are rejected before your code even runs.

atassistantapi.py — continuedFILE
class PageInfo(BaseModel):
    page: str
    title: str
    context: str
    page_vector: List[float]
    title_vector: List[float]
    context_vector: List[float]

Inside an endpoint you just write info.page, info.title… and trust the data is present and correctly typed — the validation already happened.
