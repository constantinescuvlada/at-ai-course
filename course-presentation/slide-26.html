Module 3 · Database
Optional tooling

See your data: DBeaver

DBeaver is a free universal database client — one program that opens PostgreSQL, MySQL, SQLite and dozens more, so many developers use it for everything. Get the Community edition at dbeaver.io.

Connect it to our database

  • 1. Database → New Database Connection → pick PostgreSQL
  • 2. Fill the same five values (host localhost, port 5433, database at_data_db, user vlada, password abc)
  • 3. First time, DBeaver offers to download the PostgreSQL driver — accept
  • 4. Test Connection → Finish, then browse at_data or open a SQL editor

What's a driver?

A small library a tool uses to speak one specific database's protocol. DBeaver fetches the right one automatically; settings and details are in the official docs: DBeaver · PostgreSQL driver.

Nice extras: spreadsheet-style row editing, exports, and auto-drawn ER diagrams of your tables.

Pick one, or none: psql (terminal), pgAdmin (Postgres-only GUI), DBeaver (universal GUI) all show the same data. Use whichever helps you see what the next modules are doing to the table.
