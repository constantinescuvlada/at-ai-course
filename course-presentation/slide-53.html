Module 7 · Quality
How-to · before the tests

Start the system, then test it

Our tests exercise the real running system — nothing is faked. So before pytest can prove anything, the whole bot must be up. Every long-running program gets its own terminal window: it stays busy while it serves.

Checklist, in order: 1. the Postgres container (docker start at_postgres) · 2. Ollama running · 3. the API · 4. the Gradio UI.

PowerShell · terminal 1RUN
# the API
uvicorn atassistantapi:app --port 8080
PowerShell · terminal 2RUN
# the Gradio UI
python gradio_app.py

The API answers on http://localhost:8080, the chat window on http://localhost:7860. Leave both terminals open — closing one stops that part of the system.

If a test fails with connection refused, one of the four pieces above isn't running — check that first, before suspecting your code.
