Ce vei construi

Un LLM (large language model — model lingvistic mare) este un program AI care citește și scrie text — ChatGPT este exemplul celebru; al nostru rulează pe propriul tău calculator. De unul singur, un LLM știe doar ce a învățat la antrenare și poate inventa fapte cu toată încrederea. Noi vom construi un chatbot care răspunde, în schimb, din documentele tale. Fiecare întrebare face patru mișcări:

Întrebare
→
REGĂSEȘTEgăsește documentele relevante
→
AUGMENTEAZĂadaugă documentele în prompt
→
GENEREAZĂLLM-ul scrie răspunsul
Acesta este RAG — Retrieval-Augmented Generation: mai întâi regăsești faptele potrivite, apoi lași modelul să genereze un răspuns folosindu-le doar pe ele. Construim fiecare mișcare în ordine; teoria apare ca scurte paranteze „de ce" exact atunci când ai nevoie de ea.
