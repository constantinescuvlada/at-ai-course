localdb.py — inserăm un document

Acest script salvează textul unui document în tabel (embeddingurile vin la pasul următor). Un cursor este obiectul care duce SQL-ul din Python către baza de date; autocommit înseamnă „salvează modificările imediat”.

Tiparul try / except / finally: try încearcă treaba; dacă ceva crapă, except afișează eroarea în loc să oprească programul; finally închide întotdeauna conexiunea, cu sau fără succes.

localdb.pyFILE
import psycopg2

CONN_INFO = "host=localhost port=5433 dbname=at_data_db user=vlada password=abc"

def insertInfo(page, title, context):
    try:
        conn = psycopg2.connect(CONN_INFO)
        conn.autocommit = True
        cur = conn.cursor()

        cur.execute("""
            INSERT INTO at_data (page, title, context)
            VALUES (%s, %s, %s)
        """, (page, title, context))

        print("Information added!")

    except Exception as e:
        print("Error:", e)
    finally:
        if cur:
            cur.close()
        if conn:
            conn.close()

# MAIN
if __name__ == "__main__":
    page = "Why allied"
    title = "Objectivity and independence"
    context = """
As a dedicated QA vendor we are objective and independent when it
comes to the quality of your applications and IT systems. ...
"""

    insertInfo(page.strip(), title.strip(), context.strip())
PowerShellRUN
python localdb.py

Placeholder-ele %s transmit valorile separat de textul SQL — exact asta protejează interogarea de atacurile de tip „SQL injection”. .strip() elimină spațiile și liniile noi rătăcite din jurul textului.
