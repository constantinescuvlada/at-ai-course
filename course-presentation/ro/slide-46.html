gradio_app.py — vorbim cu API-ul

Gradio este o bibliotecă ce construiește o pagină web în jurul unei singure funcții Python: desenează fereastra de chat și îți apelează funcția de fiecare dată când utilizatorul trimite un mesaj. Nouă ne rămâne doar să scriem acea funcție.

Gradio ne dă history sub formă de perechi (ce a spus utilizatorul, ce a răspuns botul). Aplatizăm perechile într-o singură listă, adăugăm mesajul nou, iar requests.post îl trimite ca JSON către API-ul din Pasul 23.

gradio_app.pyFILE
import gradio as gr
import requests

API_URL = "http://localhost:8080/at_data/answer"

def ask_bot(message, history):
    """
    message: last message from user
    history: list (user_msg, bot_msg)
    """
    all_messages = []
    for user_msg, bot_msg in history:
        all_messages.append(user_msg)
        all_messages.append(bot_msg)
    all_messages.append(message)

    try:
        response = requests.post(API_URL, json=all_messages)
        response.raise_for_status()
        data = response.json()
        print(f"response {data}") #DEBUG

raise_for_status() transformă o eroare HTTP (cum ar fi 500) într-o eroare Python pe care o putem prinde. String-ul cu ghilimele triple de sub numele funcției este un docstring — documentație care trăiește în cod.

Observă stratificarea: UI-ul nu atinge niciodată baza de date sau modelul — vorbește doar cu API-ul nostru. Această separare îți permite să înlocuiești orice strat fără să le strici pe celelalte.
