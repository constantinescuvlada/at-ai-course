Modulul 3 · Baza de date
De ce funcționează

Ce este pgvector?

O bază de date este un program care stochează date în tabele — rânduri și coloane, ca într-un spreadsheet — și răspunde la întrebări despre ele într-un limbaj numit SQL („dă-mi fiecare rând în care…”). PostgreSQL (sau simplu „Postgres”) este una dintre cele mai populare baze de date gratuite din lume; ea va păstra toate documentele noastre.

Problema: o bază de date obișnuită potrivește doar cuvinte exacte. Caută „politica de concedii” și nu va găsi niciodată documentul intitulat „reguli pentru zilele libere” — cuvinte diferite, același sens. Un chatbot are nevoie să caute după sens.

pgvector este un plug-in (o „extensie”) pentru Postgres care rezolvă exact această problemă. Adaugă un singur tip nou de coloană — vector — astfel încât fiecare rând să poată stoca sensul textului său ca 768 de numere (embedding-ul), plus operatori noi pentru compararea acelor numere:

Cum funcționează căutarea după sens

  • 1. Fiecare rând-document își stochează numerele de sens într-o coloană vector(768)
  • 2. Când sosește o întrebare, este transformată în numere în același fel
  • 3. Operatorul <=> măsoară cât de departe sunt unul de altul doi vectori de sens
  • 4. Sortează după acea distanță — primele rânduri sunt cele mai apropiate ca sens, chiar și fără niciun cuvânt comun
-- a normal table... plus a vector column
context         TEXT,           -- the document text
context_vector  vector(768)   -- its meaning, as numbers

-- find the 5 rows closest in meaning to a question
ORDER BY context_vector <=> :question
LIMIT 5;

Tot restul rămâne Postgres obișnuit: același SQL, aceleași instrumente — vectorii trăiesc pur și simplu lângă textul pe care îl descriu.

Bine de știut: o extensie se activează o singură dată per bază de date cu CREATE EXTENSION (o vei face la Pasul 9). Există baze de date vectoriale dedicate (Pinecone, Chroma, FAISS), dar a păstra textul și vectorii într-o singură bază de date familiară este mai simplu — iar imaginea Docker ankane/pgvector vine cu Postgres și extensia preinstalată, motiv pentru care Pasul 8 o folosește.
