Pornește PostgreSQL + pgvector în Docker

E timpul să pornim baza de date. docker pull descarcă imaginea (șablonul) din catalogul public Docker; docker run creează apoi din ea un container viu și îl pornește.

Flag-urile -e setează numele de utilizator, parola și numele bazei de date — codul nostru Python se va autentifica mai târziu exact cu aceste valori.

PowerShellRUN
docker pull ankane/pgvector

docker run -e POSTGRES_USER=vlada -e POSTGRES_PASSWORD=abc `
    -e POSTGRES_DB=at_data_db `
    -v C:/Users/you/ai-bot-learn/postgres:/var/lib/postgresql/data `
    --name at_postgres -p 5433:5432 -d ankane/pgvector

-v mapează datele containerului pe folderul tău postgres/, astfel încât datele supraviețuiesc repornirilor. -p 5433:5432 leagă ușa internă a containerului (portul 5432) de ușa 5433 de pe mașina ta — aceasta este adresa pe care o va folosi codul nostru. -d îl rulează în fundal.

L-ai creat deja înainte? Containerul există deja — rulează pur și simplu docker start at_postgres.
