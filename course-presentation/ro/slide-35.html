atassistantapi.py — schelet & configurare

Un API este un program care răspunde la cereri prin HTTP — același protocol pe care îl vorbește browserul tău. Fiecare URL la care răspunde se numește endpoint. API-ul nostru va fi creierul botului: alte programe îi pun întrebări, iar el răspunde cu date.

FastAPI este un framework Python care transformă funcții obișnuite în endpoint-uri. Creează atassistantapi.py cu importurile, obiectul aplicației și setările pentru conectarea la baza de date și la model.
