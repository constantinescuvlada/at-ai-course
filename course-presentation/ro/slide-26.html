Modulul 3 · Baza de date
Instrumente opționale

pgAdmin în practică: Query Tool

Odată conectat, pgAdmin e mai mult decât un vizualizator de tabele. Clic dreapta pe at_data_db → Query Tool și primești un editor SQL cu autocompletare, istoric și o grilă de rezultate — același SQL pe care l-ai tastat în psql, dar mai ușor de citit și de rerulat.

Sarcini de zi cu zi

  • Rulează SQL — scrii o interogare, apeși F5; rezultatele apar într-o grilă sortabilă din care poți copia.
  • Aruncă o privire la vectori — rulează interogările din dreapta; grila arată cele 768 de numere în care s-a transformat sensul unui document.
  • Editează un rând — în View/Edit Data, dublu-clic pe o celulă, o modifici, apeși F6 ca să salvezi — util pentru corectat o greșeală într-un document.
  • Export — butonul de descărcare salvează orice rezultat ca CSV.
  • Dashboard — primul tab al serverului arată grafic sesiunile și activitatea live.
-- câte rânduri au deja vectori?
SELECT count(*) FROM at_data
WHERE title_vector IS NOT NULL;

-- cum arată un „sens"?
SELECT id, title, title_vector
FROM at_data LIMIT 3;

-- cele 5 titluri cele mai apropiate ca sens de rândul 1
SELECT title FROM at_data
ORDER BY title_vector <=>
  (SELECT title_vector FROM at_data WHERE id = 1)
LIMIT 5;
Nu se conectează? Verifică dacă containerul rulează — docker ps trebuie să listeze at_postgres — și că ai folosit portul 5433: e aceeași depanare ca la Pasul 8, indiferent de client. Interogările cu vectori devin interesante după ce Pașii 11–15 încarcă și vectorizează datele.
