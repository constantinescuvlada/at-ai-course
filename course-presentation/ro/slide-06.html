Modulul 2 · Instalare
Pasul 1 din 31 · în terminal

Clonează materialele cursului de pe GitHub

Mai întâi, terminalul: o fereastră în care controlezi calculatorul tastând comenzi în loc să dai clicuri. Pe Windows se numește PowerShell — deschide meniul Start și tastează „PowerShell". Fiecare bloc întunecat RUN din acest curs se tastează acolo.

Înainte de clonare, instalează Git: descarcă installer-ul Git for Windows de pe git-scm.com, rulează-l și acceptă opțiunile implicite. Pe lângă comanda git, acesta instalează și Git Bash — un terminal în stil Linux pe care îl poți folosi în locul PowerShell pentru orice bloc RUN din acest curs.

Git este un program care ține evidența versiunilor de cod; un repository („repo") este un folder de proiect gestionat de el; site-uri precum GitHub și Bitbucket găzduiesc repo-uri online, ca echipele să le poată partaja. Materialele acestui curs stau într-un repo public pe GitHub — cel mai mare site de găzduire de cod — deci oricine le poate vedea și descărca, fără cont. git clone descarcă o copie completă pe mașina ta (merge și butonul verde Code → Download ZIP de pe pagina repo-ului).

PowerShellRUN
git clone https://github.com/constantinescuvlada/at-ai-course.git
cd at-ai-course

cd înseamnă „change directory" (schimbă directorul) — terminalul tău este acum în interiorul folderului de proiect, acolo unde trebuie rulate toate comenzile de mai târziu.

Clonarea aduce această prezentare (a ta acum, offline, în trei limbi), videoclipurile cursului și baza de cunoștințe (files/) din care botul va răspunde. Tot codul îl vei scrie chiar tu, pas cu pas — în propriul folder de proiect (de ex. my-ai-bot/).
