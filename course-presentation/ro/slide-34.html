Încărcăm fișierele .md descărcate în baza de date

Folderul clonat files/ conține documentele Markdown ale companiei, dar localdb.py inserează doar un singur exemplu scris în cod. Adăugăm un mic încărcător care parcurge folderul și inserează fiecare secțiune automat.

Fiecare fișier devine mai multe rânduri în tabel: page vine din numele fișierului, iar fiecare titlu #/## începe un rând nou — title este linia de titlu, context este textul de sub ea.

localdb.py — continuedFILE
import os

def loadFiles(folder="files"):
    for name in os.listdir(folder):
        if not name.endswith(".md"):
            continue
        with open(os.path.join(folder, name), encoding="utf-8") as f:
            text = f.read()

        page = name[:-3]                    # aboutus.md -> aboutus
        for part in text.split("\n#"):      # each heading starts a section
            lines = part.strip().lstrip("#").strip().split("\n", 1)
            if len(lines) < 2:              # heading without text: skip
                continue
            title, context = lines
            insertInfo(page, title.strip(), context.strip())

# MAIN
if __name__ == "__main__":
    loadFiles()

Înlocuiți blocul cu cele trei valori din __main__ (pașii anteriori) cu un singur apel loadFiles() și rulați o singură dată. Fiecare secțiune a fiecărui document devine propriul rând — slide-ul următor calculează embeddingurile și verifică totul.

Atenție: dacă rulați loadFiles() de două ori, toate rândurile se inserează din nou. Pentru a adăuga un singur document nou mai târziu, apelați insertInfo() cu cele trei valori ale lui (pasul 13) sau folosiți endpointul de creare de la pasul 19 (POST /at_data/).
