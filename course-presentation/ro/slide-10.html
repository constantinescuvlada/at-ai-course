Instalează Python

Python este limbajul de programare în care e scris întregul proiect — un program care citește fișierele noastre .py și le execută. Instalează-l înaintea oricărui alt lucru de pe python.org/downloads.

Windows: bifează „Add python.exe to PATH" în timpul instalării. PATH este lista de foldere în care Windows caută programe — fără asta, tastând python în terminal nu găsești nimic.
PowerShellRUN
python --version
pip --version

Ambele comenzi ar trebui să afișeze un număr de versiune. pip este instalatorul de pachete al Python — descarcă biblioteci (cod scris de alții) pe care le vom refolosi în loc să scriem totul noi.

„Command not found"? Reinstalează cu căsuța PATH bifată, apoi deschide un terminal nou.
