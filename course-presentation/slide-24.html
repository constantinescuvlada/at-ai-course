Module 3 · Database
Optional tooling

pgAdmin in practice: the Query Tool

Once connected, pgAdmin is more than a table viewer. Right-click at_data_db → Query Tool to get a SQL editor with autocomplete, history, and a results grid — the same SQL you typed in psql, but easier to read and rerun.

Everyday tasks

  • Run SQL — type a query, press F5; results land in a sortable grid you can copy from.
  • Peek at vectors — run the queries on the right; the grid shows the 768 numbers a document's meaning became.
  • Edit a row — in View/Edit Data, double-click a cell, change it, press F6 to save — handy for fixing a typo in a document.
  • Export — the download button saves any result as CSV.
  • Dashboard — the server's first tab graphs live sessions and activity.
-- how many rows already have vectors?
SELECT count(*) FROM at_data
WHERE title_vector IS NOT NULL;

-- what does a "meaning" look like?
SELECT id, title, title_vector
FROM at_data LIMIT 3;

-- 5 titles closest in meaning to row 1
SELECT title FROM at_data
ORDER BY title_vector <=>
  (SELECT title_vector FROM at_data WHERE id = 1)
LIMIT 5;
Can't connect? Check the container is up — docker ps should list at_postgres — and that you used port 5433: the same troubleshooting as Step 8, whatever the client. The vector queries become interesting after Steps 11–15 load and embed the data.
