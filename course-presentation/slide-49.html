Clean the reply & launch

Some models "think out loud" before answering, wrapping that reasoning in <think>…</think> tags — qwen3 does. Users shouldn't see it, so we keep only the text after the closing tag.

Then gr.ChatInterface wires our function into a chat page, and .launch() starts a small local web server for it. share=False keeps it private to your machine.
