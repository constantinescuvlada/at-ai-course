Step 12 of 31 · write the file

embedding.py — the calcEmbed helper

Time to write code. A function is a reusable mini-program with a name; import lets one file use code from another. Create a file named embedding.py and write the one function that turns any text into its 768 meaning-numbers.

CONN_INFO is the connection string — the database's address and login in one line (host, port 5433, name, user, password — the same values from Step 8).

embedding.pyFILE
import psycopg2
import ollama

CONN_INFO = "host=localhost port=5433 dbname=at_data_db user=vlada password=abc"

def calcEmbed(text, model="nomic-embed-text"):
    response = ollama.embeddings(
        model=model,
        prompt=text,
    )
    return response["embedding"]

ollama.embeddings(...) sends the text to the local model (through port 11434) and gets back a list of 768 numbers. Every other file in the project will import this function — change the model here and the whole system follows.
