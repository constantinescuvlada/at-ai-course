Загружаем скачанные .md-файлы в базу данных

В склонированной папке files/ лежат Markdown-документы компании, но localdb.py вставляет только один зашитый в код пример. Добавим небольшой загрузчик, который обходит папку и вставляет каждый раздел автоматически.

Каждый файл превращается в несколько строк таблицы: page берётся из имени файла, а каждый заголовок #/## начинает новую строку — title — это строка заголовка, context — текст под ней.

localdb.py — continuedFILE
import os

def loadFiles(folder="files"):
    for name in os.listdir(folder):
        if not name.endswith(".md"):
            continue
        with open(os.path.join(folder, name), encoding="utf-8") as f:
            text = f.read()

        page = name[:-3]                    # aboutus.md -> aboutus
        for part in text.split("\n#"):      # each heading starts a section
            lines = part.strip().lstrip("#").strip().split("\n", 1)
            if len(lines) < 2:              # heading without text: skip
                continue
            title, context = lines
            insertInfo(page, title.strip(), context.strip())

# MAIN
if __name__ == "__main__":
    loadFiles()

Замените блок с тремя значениями в __main__ (из предыдущих шагов) на один вызов loadFiles() и запустите один раз. Каждый раздел каждого документа станет отдельной строкой — на следующем слайде мы построим эмбеддинги и всё проверим.

Осторожно: повторный запуск loadFiles() вставит все строки ещё раз. Чтобы добавить один новый документ позже, вызовите insertInfo() с его тремя значениями (шаг 13) или используйте эндпоинт создания из шага 19 (POST /at_data/).
