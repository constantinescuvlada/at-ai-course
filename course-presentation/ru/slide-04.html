Схема проекта

Четыре программы работают вместе — и каждый квадратик на этой схеме вы построите сами. Верхний ряд — то, что происходит вживую, при каждом вопросе; нижний — делается один раз, при загрузке знаний.

Когда приходит вопрос

  • Чат (gradio_app.py) отправляет его в API.
  • API превращает вопрос в вектор (через Ollama), находит ближайшие документы в Postgres оператором <=> и передаёт их модели qwen3.
  • Модель пишет ответ только по этим документам — и он возвращается в чат.

Кто есть кто

  • gradio_app.py — окно чата (фронтенд)
  • atassistantapi.py — мозг (бэкенд-API)
  • localdb.py, embedding.py — загрузка знаний
  • PostgreSQL + pgvector — память · Ollama — локальные ИИ-модели
  • attest.py, tests/ — доказательство, что всё работает
Порты, которые стоит запомнить: чат 7860 · API 8080 · Postgres 5433 · Ollama 11434. Всё работает на вашей машине — без облака и ключей. Возвращайтесь к этому слайду, когда потеряете нить: каждый модуль заполняет один квадратик.
