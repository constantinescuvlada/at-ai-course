Установите зависимости

Зависимость — это библиотека, которая нужна нашему коду для работы. Все они перечислены в файле requirements.txt; команда pip install -r читает этот список и скачивает каждую библиотеку из PyPI (публичного каталога библиотек Python).

requirements.txt — ключевые библиотекиFILE
# excerpt — the repo file pins exact versions
# of these and everything they depend on
fastapi==0.115.12
uvicorn==0.34.2
psycopg2-binary==2.9.10
ollama==0.4.8
gradio==5.30.0
requests==2.32.3
pytest==8.3.5
PowerShellRUN
pip install -r requirements.txt

Для чего нужна каждая библиотека

  • fastapi — веб-фреймворк: превращает наши функции Python в эндпоинты API
  • uvicorn — сервер, который собственно и запускает приложение FastAPI на порту 8080
  • psycopg2-binary — драйвер PostgreSQL: позволяет Python отправлять SQL в базу данных
  • ollama — клиент локальных AI-моделей: эмбеддинги + ответы в чате
  • gradio — строит интерфейс окна чата в несколько строк на Python
  • requests — выполняет HTTP-запросы: так интерфейс и тесты обращаются к API
  • pytest — находит и запускает интеграционные тесты в attest.py
