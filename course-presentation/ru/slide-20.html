Почему это работает

Что такое pgvector?

База данных — это программа, которая хранит данные в таблицах — строки и столбцы, как в электронной таблице — и отвечает на вопросы о них на языке под названием SQL («выдай мне все строки, где…»). PostgreSQL (или просто «Postgres») — одна из самых популярных бесплатных баз данных в мире; в ней будут храниться все наши документы.

Проблема: обычная база данных сопоставляет только точные слова. Поищите «политика отпусков» — и она никогда не найдёт документ с названием «правила выходных»: слова разные, смысл один. Чат-боту нужен поиск по смыслу.

pgvector — это плагин («расширение») для Postgres, который решает ровно эту задачу. Он добавляет один новый тип столбца — vector — чтобы каждая строка могла хранить смысл своего текста в виде 768 чисел (эмбеддинг), плюс новые операторы для сравнения этих чисел:

Как работает поиск по смыслу

  • 1. Каждая строка-документ хранит свои «числа смысла» в столбце vector(768)
  • 2. Когда приходит вопрос, он превращается в числа тем же способом
  • 3. Оператор <=> измеряет, насколько далеко друг от друга находятся два вектора смысла
  • 4. Сортируем по этому расстоянию — верхние строки окажутся ближайшими по смыслу, даже без единого общего слова
-- a normal table... plus a vector column
context         TEXT,           -- the document text
context_vector  vector(768)   -- its meaning, as numbers

-- find the 5 rows closest in meaning to a question
ORDER BY context_vector <=> :question
LIMIT 5;

Всё остальное остаётся обычным Postgres: тот же SQL, те же инструменты — векторы просто живут рядом с текстом, который они описывают.

Полезно знать: расширение включается один раз для каждой базы командой CREATE EXTENSION (вы сделаете это на шаге 9). Существуют специализированные векторные базы данных (Pinecone, Chroma, FAISS), но держать текст и векторы в одной привычной базе проще — а Docker-образ ankane/pgvector поставляет Postgres с уже установленным расширением, поэтому на шаге 8 мы используем именно его.
