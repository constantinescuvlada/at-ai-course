Запускаем PostgreSQL + pgvector в Docker

Пора запустить базу данных. docker pull скачивает образ (шаблон) из публичного каталога Docker; затем docker run создаёт из него живой контейнер и запускает его.

Флаги -e задают имя пользователя, пароль и имя базы данных — позже наш Python-код будет входить именно с этими данными.

PowerShellRUN
docker pull ankane/pgvector

docker run -e POSTGRES_USER=vlada -e POSTGRES_PASSWORD=abc `
    -e POSTGRES_DB=at_data_db `
    -v C:/Users/you/my-ai-bot/postgres:/var/lib/postgresql/data `
    --name at_postgres -p 5433:5432 -d ankane/pgvector

-v отображает данные контейнера на вашу папку postgres/, поэтому данные переживают перезапуски. -p 5433:5432 соединяет внутреннюю дверь контейнера (порт 5432) с дверью 5433 на вашей машине — именно по этому адресу будет обращаться наш код. -d запускает контейнер в фоне.

Уже создавали его раньше? Контейнер уже существует — просто выполните docker start at_postgres.
