Selenium E2E-тест на self-hosted runner

До сих пор наши pytest-тесты обращались к API напрямую. Selenium-тест идёт дальше: он открывает настоящий браузер и кликает по интерфейсу Gradio как пользователь. Запускаем его через GitHub Actions на self-hosted runner, а браузеры подаёт Selenoid из Docker.

Сначала расширим проект: две новые строки в requirements.txt и добавим *.mp4 в .gitignore — тест записывает видео сессий, которые не нужно коммитить.

requirements.txt — добавьтеFILE
selenium==4.47.0
pydantic==2.13.4
.gitignore — добавьтеFILE
*.mp4
ТерминалRUN
# GitHub -> Settings -> Actions -> Runners -> «New self-hosted runner» -> Linux, скопируйте токен
cd runner
export RUNNER_TOKEN="AL24XXYU67ZWQ6WUDIXYIN3KSXXXX"
docker compose up -d
ТерминалRUN
cd selenoid
./start-selenoid.sh    # панель: http://localhost:8082

cd ../tests
pytest seleniumtest.py::test_open_gradio_app -v

1 · Runner: на GitHub откройте Settings → Actions → Runners, нажмите New self-hosted runner, выберите Linux и скопируйте токен в команду слева (выполняется в локальной папке runner/). Обновите страницу — в списке появится новый runner local-docker-runner1.

2 · Selenoid: start-selenoid.sh (в папке selenoid/) поднимает контейнеры с браузерами — проверьте панель на http://localhost:8082. 3 · Тест: из папки tests/ запустите test_open_gradio_app из seleniumtest.py — он открывает приложение Gradio в Chrome внутри Selenoid.
