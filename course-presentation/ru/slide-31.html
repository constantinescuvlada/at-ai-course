localdb.py — вставляем документ

Этот скрипт сохраняет текст одного документа в таблицу (эмбеддинги — на следующем шаге). Курсор — это объект, который передаёт SQL из Python в базу данных; autocommit означает «сохранять изменения сразу».

Паттерн try / except / finally: try — пробуем выполнить работу; если что-то падает, except печатает ошибку вместо аварийного завершения; finally всегда закрывает соединение — и при успехе, и при ошибке.

localdb.pyFILE
import psycopg2

CONN_INFO = "host=localhost port=5433 dbname=at_data_db user=vlada password=abc"

def insertInfo(page, title, context):
    try:
        conn = psycopg2.connect(CONN_INFO)
        conn.autocommit = True
        cur = conn.cursor()

        cur.execute("""
            INSERT INTO at_data (page, title, context)
            VALUES (%s, %s, %s)
        """, (page, title, context))

        print("Information added!")

    except Exception as e:
        print("Error:", e)
    finally:
        if cur:
            cur.close()
        if conn:
            conn.close()

# MAIN
if __name__ == "__main__":
    page = "Why allied"
    title = "Objectivity and independence"
    context = """
As a dedicated QA vendor we are objective and independent when it
comes to the quality of your applications and IT systems. ...
"""

    insertInfo(page.strip(), title.strip(), context.strip())
PowerShellRUN
python localdb.py
Information added!

Плейсхолдеры %s передают значения отдельно от текста SQL — именно это защищает запрос от атак «SQL-инъекция». .strip() убирает лишние пробелы и переводы строк вокруг текста.

if __name__ == "__main__": означает: выполнять эту часть только тогда, когда файл запущен напрямую. Меняйте три значения и перезапускайте скрипт для каждого документа, который хотите загрузить.
