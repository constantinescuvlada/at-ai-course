pgAdmin на практике: Query Tool

После подключения pgAdmin — больше, чем просмотрщик таблиц. Клик правой кнопкой по at_data_db → Query Tool — и у вас редактор SQL с автодополнением, историей и сеткой результатов: тот же SQL, что вы набирали в psql, только его легче читать и перезапускать.

Повседневные задачи

  • Выполнить SQL — наберите запрос и нажмите F5; результаты появятся в сортируемой сетке, откуда их можно копировать.
  • Заглянуть в векторы — выполните запросы справа; сетка покажет 768 чисел, в которые превратился смысл документа.
  • Править строку — в View/Edit Data дважды кликните по ячейке, измените её и нажмите F6, чтобы сохранить — удобно исправлять опечатку в документе.
  • Экспорт — кнопка загрузки сохраняет любой результат в CSV.
  • Dashboard — первая вкладка сервера рисует графики живых сессий и активности.
-- у скольких строк уже есть векторы?
SELECT count(*) FROM at_data
WHERE title_vector IS NOT NULL;

-- как выглядит «смысл»?
SELECT id, title, title_vector
FROM at_data LIMIT 3;

-- 5 заголовков, ближайших по смыслу к строке 1
SELECT title FROM at_data
ORDER BY title_vector <=>
  (SELECT title_vector FROM at_data WHERE id = 1)
LIMIT 5;
Не подключается? Проверьте, что контейнер запущен — docker ps должен показать at_postgres — и что указан порт 5433: это та же диагностика, что и на шаге 8, каким бы ни был клиент. Запросы с векторами станут интересными после того, как шаги 11–15 загрузят и векторизуют данные.
