Дополнительные инструменты

Смотрим на данные: pgAdmin

До сих пор вы общались с базой данных только текстом через psql. GUI-клиент (графический интерфейс) показывает ту же базу визуально — таблицы как кликабельное дерево, строки как электронную таблицу. pgAdmin — официальный бесплатный GUI для PostgreSQL; скачать его можно на pgadmin.org.

Подключаем его к нашей базе

  • 1. Правый клик по Servers → Register → Server
  • 2. Вкладка General → любое имя, например at_postgres
  • 3. Вкладка Connection → пять значений справа — те же, что на шаге 8
  • 4. Пройдите по дереву: Databases → at_data_db → Schemas → public → Tables → at_data, затем правый клик → View/Edit Data, чтобы увидеть свои 149 строк
# connection settings (any client)
Host:      localhost
Port:      5433
Database:  at_data_db
Username:  vlada
Password:  abc

Его Query Tool тоже выполняет SQL — те же команды, что вы вводили на шагах 9–10.

Ничего нового не происходит: psql и pgAdmin — это два окна в одну и ту же живую базу данных. GUI просто удобнее для исследования — сам курс требует только psql.
