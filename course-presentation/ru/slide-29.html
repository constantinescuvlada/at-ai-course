embedding.py — хелпер calcEmbed

Пора писать код. Функция — это переиспользуемая мини-программа с именем; import позволяет одному файлу использовать код из другого. Создайте файл с именем embedding.py и напишите единственную функцию, которая превращает любой текст в его 768 «чисел смысла».

CONN_INFO — это строка подключения: адрес базы данных и данные для входа в одной строке (хост, порт 5433, имя базы, пользователь, пароль — те же значения из шага 8).

embedding.pyFILE
import psycopg2
import ollama

CONN_INFO = "host=localhost port=5433 dbname=at_data_db user=vlada password=abc"

def calcEmbed(text, model="nomic-embed-text"):
    response = ollama.embeddings(
        model=model,
        prompt=text,
    )
    return response["embedding"]

ollama.embeddings(...) отправляет текст локальной модели (через порт 11434) и получает обратно список из 768 чисел. Все остальные файлы проекта будут делать import этой функции — смените модель здесь, и вся система последует за ней.
