Очищаем ответ и запускаем

Некоторые модели «думают вслух» перед ответом, оборачивая рассуждения в теги <think>…</think> — так делает qwen3. Пользователи не должны это видеть, поэтому мы оставляем только текст после закрывающего тега.

Затем gr.ChatInterface подключает нашу функцию к странице чата, а .launch() запускает для неё небольшой локальный веб-сервер. share=False оставляет её доступной только на вашей машине.

gradio_app.py — продолжениеFILE
        parts = data["answer"].split("</think>")
        if len(parts) > 1:
            answer = parts[1]
        else:
            answer = parts[0]

        return answer.strip()
    except requests.exceptions.RequestException as e:

gr.ChatInterface(
    fn=ask_bot,
    chatbot=gr.Chatbot(height=400),
    textbox=gr.Textbox(placeholder="Ask question", container=False),
    title="🔨AT AI assistant",
    description="Your helpful assistant and best friend :)",
    theme="default"
).launch(share=False)

Три ветки except возвращают понятные сообщения об ошибках прямо в чат, вместо того чтобы уронить окно: API недоступен, неожиданный формат ответа или что-то ещё.
