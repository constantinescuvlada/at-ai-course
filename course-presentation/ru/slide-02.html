Главная идея (30 секунд)

Что мы построим

LLM (большая языковая модель) — это ИИ-программа, которая читает и пишет текст; ChatGPT — самый известный пример, а наша работает на вашем собственном компьютере. Сама по себе LLM знает только то, на чём её обучали, и может уверенно выдумывать факты. Мы построим чат-бота, который вместо этого отвечает по вашим документам. Каждый вопрос проходит четыре шага:

Вопрос
→
ИЗВЛЕЧЬнайти нужные документы
→
ДОПОЛНИТЬдобавить документы в промпт
→
СГЕНЕРИРОВАТЬLLM пишет ответ
Это и есть RAG — Retrieval-Augmented Generation: сначала извлекаем нужные факты, затем модель генерирует ответ, опираясь только на них. Мы строим каждый шаг по порядку; теория появляется короткими вставками «почему» ровно тогда, когда она нужна.
