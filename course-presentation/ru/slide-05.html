Клонируйте материалы курса с GitHub

Сначала — терминал: окно, в котором вы управляете компьютером, набирая команды вместо кликов мышью. В Windows он называется PowerShell — откройте меню «Пуск» и наберите «PowerShell». Каждый тёмный блок RUN в этом курсе вводится именно там.

Перед клонированием установите Git: скачайте установщик Git for Windows с git-scm.com, запустите его и примите настройки по умолчанию. Вместе с командой git он устанавливает Git Bash — терминал в стиле Linux, который можно использовать вместо PowerShell для любого блока RUN в этом курсе.

Git — программа, которая отслеживает версии кода; репозиторий («репо») — папка проекта, которой он управляет; сайты вроде GitHub и Bitbucket хранят репозитории онлайн, чтобы команды могли ими делиться. Материалы этого курса лежат в публичном репозитории на GitHub — крупнейшем сайте для хостинга кода — так что смотреть и скачивать их может кто угодно, без аккаунта. git clone скачивает полную копию на вашу машину (зелёная кнопка Code → Download ZIP на странице репозитория тоже подойдёт).

PowerShellRUN
git clone https://github.com/constantinescuvlada/at-ai-course.git
cd at-ai-course

cd означает «change directory» (сменить каталог) — теперь терминал находится внутри папки проекта, где и должны выполняться все дальнейшие команды.

Клон приносит эту презентацию (теперь она у вас, офлайн, на трёх языках), видео курса и базу знаний (files/), по которой бот будет отвечать. Весь код вы напишете сами, шаг за шагом — в собственной папке проекта (например, my-ai-bot/).
