Создайте свой публичный репозиторий

Папка, которую вы клонировали, — это материалы курса: как учебник — вы его читаете, а git pull обновляет. Весь код, который вы напишете на курсе, живёт в вашем собственном репозитории — это ваша тетрадь, а позже и портфолио.

На github.com: 1. «+» справа вверху → New repository · 2. имя my-ai-bot · 3. выберите Public — публичный репозиторий виден всем и работает как портфолио · 4. все галочки оставьте ВЫКЛюченными (без README) — пустой репозиторий проще подключить · 5. Create repository.

PowerShellRUN
# рядом с at-ai-course, НЕ внутри неё
mkdir my-ai-bot
cd my-ai-bot
git init
git remote add origin https://github.com/ВАШ_ЛОГИН/my-ai-bot.git

echo "# My AI Bot" > README.md
git add .
git commit -m "First commit"
git push -u origin main

git init велит Git следить за этой папкой; remote add origin сохраняет адрес, куда пушить (скопируйте его со страницы нового репозитория). Первый push один раз попросит войти в GitHub — потом обновите страницу в браузере: ваш код в интернете.

Если Git спросит, кто вы: git config --global user.name "Имя Фамилия" и git config --global user.email "почта@как-на-github", затем повторите коммит. Если ветка называется master: git branch -M main.
