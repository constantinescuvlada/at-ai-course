Запускаем всё — порядок важен

Ваша повседневная последовательность запуска. Порядок не обсуждается: каждый слой зависит от предыдущего — UI вызывает API, API обращается к базе данных и моделям.

1 · БД:5433
→
2 · Ollamaмодели
→
3 · API:8080
→
4 · UI:7860
PowerShellRUN
docker start at_postgres                   # 1 - database
# 2 - Ollama already runs in the background
uvicorn atassistantapi:app --port 8080     # 3 - terminal A
python gradio_app.py                       # 4 - terminal B

Запускайте снизу вверх, останавливайте сверху вниз. Если слой барахлит, сначала проверьте тот, что под ним — «сломанный» UI обычно оказывается просто незапущенным API.
