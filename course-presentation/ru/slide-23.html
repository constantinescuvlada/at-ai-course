Создаём таблицу

Таблица — это сетка: каждая строка — одна запись, каждый столбец — одно её свойство. Наша таблица хранит по одному фрагменту документа в строке: три текстовых столбца плюс вектор из 768 чисел для каждого из них.

SERIAL PRIMARY KEY означает, что столбец id нумеруется автоматически (1, 2, 3…) и однозначно идентифицирует каждую строку. TEXT хранит текст любой длины.

psql — SQL shellRUN
CREATE TABLE at_data (
  id              SERIAL PRIMARY KEY,
  page            TEXT,
  title           TEXT,
  context         TEXT,
  page_vector     vector(768),
  title_vector    vector(768),
  context_vector  vector(768)
);

Почему 768? Именно столько чисел выдаёт nomic-embed-text для каждого текста — размер столбца должен точно совпадать с моделью, иначе вставки будут завершаться ошибкой.

Введите \q, чтобы выйти из psql и вернуться в PowerShell.
