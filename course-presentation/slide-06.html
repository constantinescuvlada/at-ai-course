Module 2 · Setup
Step 1 of 31 · in your terminal

Clone the course materials from GitHub

First, the terminal: a window where you control the computer by typing commands instead of clicking. On Windows it's called PowerShell — open the Start menu and type "PowerShell". Every dark RUN block in this course is typed there.

Before cloning, install Git: download the Git for Windows installer from git-scm.com, run it, and accept the default options. Along with the git command it installs Git Bash — a Linux-style terminal you can use instead of PowerShell for any RUN block in this course.

Git is a program that tracks versions of code; a repository ("repo") is a project folder it manages; websites like GitHub and Bitbucket host repos online so teams can share them. This course's materials live in a public repo on GitHub — the largest code-hosting site — so anyone can view and download them, no account needed. git clone downloads a complete copy to your machine (the green Code → Download ZIP button on the repo page works too).

PowerShellRUN
git clone https://github.com/constantinescuvlada/at-ai-course.git
cd at-ai-course

cd means "change directory" — your terminal is now inside the project folder, which is where all later commands must run.

The clone brings this presentation (yours now, offline, in three languages), the course videos, and the knowledge base (files/) the bot will answer from. All the code you'll write yourself, step by step — in your own project folder (e.g. my-ai-bot/).
