Module 3 · Database
Why it works

PostgreSQL — the database under everything

Steps 8–10 run PostgreSQL ("Postgres") — a free, open-source relational database: it keeps data in tables of rows and columns and answers questions written in SQL. Developed in the open for ~30 years, it powers banks, airlines and much of the web — and it is the database you are most likely to meet at work.

Why Postgres for this project

  • Free & everywhere — no license; runs the same on your laptop (in Docker) and on a production server.
  • Extensions — Postgres can learn new tricks; pgvector (next slide) teaches it to store and compare embeddings.
  • One home for everything — the documents and their meaning-vectors live in the same table, so one SQL query does normal filtering and meaning-search together.
  • Reliability — transactions guarantee a crash never leaves half-written data.
-- SQL reads almost like English
SELECT title, page
FROM at_data
WHERE title LIKE '%QA%'
LIMIT 3;

The words you'll keep hearing: the server is the running Postgres program; a database (ours: at_data_db) is a named collection of tables (ours: at_data); psql is its built-in command-line client; SQL is the language they all speak.

Ports: Postgres normally listens on port 5432. Our container maps it to 5433 on your machine so it can never clash with a Postgres someone already installed — that's why every connection in this course says port=5433.
