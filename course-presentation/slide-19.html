Start PostgreSQL + pgvector in Docker

Time to start the database. docker pull downloads the image (the blueprint) from Docker's public catalog; docker run then creates and starts a live container from it.

The -e flags set the database's username, password, and database name — our Python code will log in with exactly these later.

PowerShellRUN
docker pull ankane/pgvector

docker run -e POSTGRES_USER=vlada -e POSTGRES_PASSWORD=abc `
    -e POSTGRES_DB=at_data_db `
    -v C:/Users/you/ai-bot-learn/postgres:/var/lib/postgresql/data `
    --name at_postgres -p 5433:5432 -d ankane/pgvector

-v maps the container's data onto your postgres/ folder, so the data survives restarts. -p 5433:5432 connects the container's internal door (port 5432) to door 5433 on your machine — that's the address our code will use. -d runs it in the background.

Created it before? The container already exists — just docker start at_postgres.
