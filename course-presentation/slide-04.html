When a question arrives

  • The chat (gradio_app.py) sends it to the API.
  • The API turns it into a vector (via Ollama), finds the closest documents in Postgres with <=>, and hands them to the qwen3 model.
  • The model writes an answer from those documents only — and it travels back into the chat.

Who is who

  • gradio_app.py — the chat window (frontend)
  • atassistantapi.py — the brain (backend API)
  • localdb.py, embedding.py — load the knowledge
  • PostgreSQL + pgvector — the memory · Ollama — the local AI models
  • attest.py, tests/ — the proof it all works
Ports to remember: chat 7860 · API 8080 · Postgres 5433 · Ollama 11434. Everything runs on your machine — no cloud, no keys. Come back to this slide whenever you lose the thread: every module fills in one box.
